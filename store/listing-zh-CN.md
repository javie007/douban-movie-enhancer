# Chrome Web Store 商品详情（zh-CN）

## 名称

豆瓣选电影增强

## 简短说明

在豆瓣电影“选电影”页面补回缺失的“剧情”类型筛选，并复用豆瓣原生结果与筛选体验。

## 详细说明

豆瓣电影“选电影”页面的类型筛选支持喜剧、爱情、动作等多种类型，但当前列表里缺少常用的“剧情”。

“豆瓣选电影增强”会在左侧“类型”下拉框中加入“剧情”。点击后，页面继续使用豆瓣原生的筛选状态与推荐接口，因此地区、年代、排序、评分区间、可播放和加载更多都可以照常组合使用。

主要特点：

- “剧情”位于“全部”之后，和其他类型保持一致；
- 不重新制作或伪造电影列表；
- 不收集或保存用户数据；
- 不申请扩展权限；
- 没有后台服务、分析、广告或远程代码；
- 页面结构不兼容时安全退出，不影响豆瓣原页面。

使用方法：

1. 安装扩展并刷新豆瓣电影“选电影”页面；
2. 点击顶部“全部”；
3. 打开左侧“类型”；
4. 选择“剧情”。

本扩展是非豆瓣官方的第三方页面增强工具，与豆瓣及其关联公司无隶属、授权或合作关系。

## 单一用途说明

本扩展的唯一用途是在豆瓣电影“选电影”页面的类型选择器中补充“剧情”，并让该选择通过豆瓣页面自身的筛选逻辑生效。

## 权限说明

扩展不申请 `permissions` 或 `host_permissions`。内容脚本仅匹配豆瓣电影“选电影”URL，并在运行时再次校验路径。使用 `MAIN` world 是为了让新增类型进入页面现有 React 组件，从而复用其原生点击事件和请求逻辑。

## 数据使用披露

- 不收集个人身份信息；
- 不收集健康、金融、身份验证或通信数据；
- 不收集位置、浏览历史或网站内容；
- 不使用数据进行广告、分析或个性化；
- 不向第三方出售或传输数据。
